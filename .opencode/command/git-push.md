description: Git add, commit und push mit deutscher Commit-Message
---

Führe folgende Schritte aus:
1. `git status` und `git diff --stat` prüfen
2. `git add -A`
3. Commit mit deutscher Kurzbeschreibung der Änderungen
4. Falls package.json version geändert: `git tag v{neue_version}`
5. `git push origin main --tags`
